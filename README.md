# Digital Clock

A simple and responsive digital clock built using HTML5, CSS3, and JavaScript.

## Features

- Displays hours, minutes, and seconds
- Updates automatically every second
- Uses leading zeros for single-digit values
- Simple and responsive design
- Easy-to-use interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

The JavaScript `Date` object is used to get the current time.  
The `setInterval()` function updates the clock every second, and the DOM is updated to display the current hours, minutes, and seconds.
